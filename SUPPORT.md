# Support

RCC-OS is an experimental research lab, not a product. Support is
best-effort and limited to GitHub issues.

For security issues, see [`SECURITY.md`](../SECURITY.md) instead of
filing a public issue.

For background on the upstream project that this lab derives from,
see [ResonantOS/2.0.0-alpha](https://github.com/ResonantOS/2.0.0-alpha).
