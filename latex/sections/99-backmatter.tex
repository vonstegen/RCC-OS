\section{Colophon}

This document is typeset with \RCCOS{}'s lab document class
(\texttt{classes/rccos.cls}) on top of the standard \LaTeX{}
\texttt{book} class, with the \texttt{lmodern} font and
\texttt{microtype} protrusions. Bibliography is managed with
\texttt{biblatex} and \texttt{biber} (IEEE style). Cross-references
are routed through \texttt{cleveref}. Code listings use the
\texttt{listings} package.

To rebuild locally:

\begin{lstlisting}[language=bash]
make            # build the PDF into build/main.pdf
make watch      # rebuild on change
make spelling   # run ltex prose lint
\end{lstlisting}
