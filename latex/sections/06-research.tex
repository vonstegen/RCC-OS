\section{Open questions}

\begin{enumerate}
  \item What is the smallest Cognitive Core that satisfies the
        routing-accuracy threshold in Stage 2?
  \item Does the lab need to train a ResonantOS-specific ternary
        model, or is BitNet b1.58 2B4T a sufficient starting point?
  \item How does the Cognitive Core behave under adversarial
        prompts? (See \texttt{docs/notes/adversarial-prompts.tex}
        for the threat model.)
  \item Can the deterministic Core be hardened to a small TCB
        suitable for verified-build claims?
  \item What is the right IPC transport for the Resonant Core?
        Loopback HTTP, Unix socket, or named pipe?
\end{enumerate}

\section{Methodology}

The lab's research methodology is intentionally boring:

\begin{enumerate}
  \item Formulate a falsifiable hypothesis.
  \item Pick a measurement script before writing code.
  \item Run the measurement three times on three different machines.
  \item Record the result in this chapter, regardless of outcome.
  \item If the result contradicts the hypothesis, prefer the
        evidence and amend the plan.
\end{enumerate}

\section{Reproduction}

fresh checkout by running a single command. The command is
recorded next to the measurement.
