## Process

1. Open a PR adding a new `NNNN-*.md` file under this directory.
2. Reference the decision from the relevant milestone or component
   README.
3. Decisions may be **superseded** by a later decision; the original
   is never deleted, only annotated with `Superseded by NNNN`.
